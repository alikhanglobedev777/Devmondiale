Frequently asked questions

A few useful answers

Do you develop websites as well as web applications?

Yes. A company website and a more complex web application have different goals; we clarify those before suggesting an approach.

Will the website work on phones?

Responsive layouts are part of the project scope, with key content and interactions checked at mobile sizes.

Can our website connect with a CRM or other system?

It can when the required integration is supported and the relevant data access is available. We assess those dependencies in planning.
